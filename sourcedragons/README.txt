Source Dragon Powers - Fabric mod, Minecraft Java 1.21.1

ONE-CLICK INSTALL (PC or Mac)
1. Install the Modrinth App (modrinth.com/app) once.
2. Make a free GitHub account, create a repository, upload this whole folder
   (including the hidden .github folder), and wait about 3 minutes.
3. On the repository page, open Releases (right side) and click
   SourceDragonPowers.mrpack to download it.
4. Double-click the .mrpack file. Modrinth App opens and installs Minecraft 1.21.1 +
   Fabric + Fabric API + this mod. Press Play.
   (If double-click does nothing: Modrinth App > Add instance > Import from file.)

OR BUILD YOURSELF (JDK 21): copy gradlew, gradlew.bat and gradle/ from
https://fabricmc.net/develop/template into this folder, then run ./gradlew build.
The jar is build/libs/sourcedragons-1.0.0.jar (not the -sources jar).

POWERS (3 second cooldown)   Holding it         Right-click
Fire Essence                 Fire resistance    Fireball
Ice Essence                  Slow falling       Freezes and slows mobs within 6 blocks
Earth Essence                Resistance         Shockwave, damage and launch mobs
Lightning Essence            Speed II           Lightning where you look
Tech Essence                 Haste II           Scan pulse: mobs within 16 blocks glow and get weak, you get Haste III
Life Essence                 Regeneration       Heals you and nearby players, grows crops within 4 blocks

DRAGONIOUS FORM
Dragonious Core: craft with all six essences + a nether star (shapeless).
Right-click for 60 seconds of Strength III, Speed III, Resistance II, Regeneration II,
Jump Boost IV, Haste II, fire resistance, slow falling and night vision.
Cooldown: 5 minutes.

ESSENCE RECIPES (shapeless): dragon breath + diamond +
Fire: blaze rod + magma block | Ice: blue ice + packed ice
Earth: emerald + mossy cobblestone | Lightning: lightning rod + copper block
Tech: redstone block + observer | Life: golden apple + moss block
